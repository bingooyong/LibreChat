# 审查清单

逐项过一遍。每项记录：命中与否、原文、定位、风险。

## 一、文件完整性

- [ ] 招标文件正文（非目录、非封面）是否完整可读
- [ ] 是否存在扫描件/图片型 PDF（需 OCR，文字层可能缺失）
- [ ] 是否有加密或权限受限的章节
- [ ] 补遗、答疑、澄清文件是否齐备
- [ ] 补遗是否覆盖了正文条款（列出被修改的条款编号）

## 二、时间节点

- [ ] 投标截止时间（精确到时分，注意时区）
- [ ] 开标时间
- [ ] 保证金/保函到账截止时间（通常早于投标截止）
- [ ] 招标文件澄清提问截止时间（可能已过）
- [ ] 证书有效期覆盖投标有效期
- [ ] 投标有效期是否满足最短要求

## 三、资格条件（逐条）

- [ ] 营业执照 / 经营范围覆盖标的
- [ ] 行业资质等级要求（如 CMMI、ITSS、ISO、CCC 等）及等级门槛
- [ ] 安全生产许可证 / 排污许可证（按需）
- [ ] 产品认证（3C、CE、UL、软件著作权等）
- [ ] 业绩要求：数量、单项目合同额、时间区间、甲方类型
- [ ] 关键人员：岗位、职称、执业资格、社保要求、在职证明
- [ ] 财务指标：注册资本、净资产、营收、审计报告年份、资产负债率
- [ ] 是否允许联合体；允许时的资质门槛与牵头方要求
- [ ] 制造商授权书 / 代理资格要求
- [ ] 信用记录要求（信用中国 / 政府采购严重违法失信名单）

## 四、否决项（废标条款）

对每条记录后果。常见类型：

- [ ] 投标文件未按要求签字盖章
- [ ] 未按要求密封/标记
- [ ] 投标保证金缺失、金额不足、形式不符（现金/保函/保函有效期）
- [ ] 报价超过最高限价 / 超过预算
- [ ] 投标有效期不足
- [ ] 资格条件任一项不满足
- [ ] 关键人员与实际不符或未到场
- [ ] 联合体协议缺失或不合规
- [ ] 存在「一票否决」的单项条款（重点逐字找）
- [ ] 未按格式提交报价清单 / 偏离表
- [ ] 技术方案未响应实质性条款

## 五、评分规则

- [ ] 评分方法（综合评分法 / 最低价法 / 性价比法）
- [ ] 各分项满分值与计算方式
- [ ] 价格分计算公式（基准价推导方式）
- [ ] 客观分（可程序化）与主观分（需评委）的分界
- [ ] **总分一致性校验**：分项之和 == 声明总分？（不一致则列出差异）
- [ ] 是否有价格分扣分上限、价格异常低价处理条款
- [ ] 是否有评分项与资格条件重复计分（常见争议点）

## 六、技术要求

- [ ] 是否含「★」或「必须」字样的实质性条款
- [ ] 参数是否逐条可测（避免「先进」「优质」等模糊表述）
- [ ] 是否要求提供检测报告/第三方认证
- [ ] 是否指定品牌或指定档次（关注「或相当于」表述）
- [ ] 是否有交付周期、质保期、响应时间等硬性承诺
- [ ] 是否要求现场演示、试用、驻场服务

## 七、常见陷阱

- 资格条件藏在「投标人须知前附表」而非正文
- 否决项藏在合同条款或评标办法附表
- 评分表与正文分册，页码不连续
- 补遗把参数放宽或收紧但未标红
- 业绩要求暗含「同类项目」（需确认界定口径）
- 联合体各方均须满足全部资质，而非分工
- 保证金金额按预算比例计算，需确认取整方式
- 报价表分项合计与总价可能不一致
- 「不得低于成本价」条款导致低价废标

## 八、需要人工确认

列出所有无法从文档单独判定的事项，例如：

- 条款表述有歧义（「原则上」「原则上不低于」）
- 参数表述可多解
- 补遗与正文冲突且未标优先级
- 依赖第三方检测报告才能确认
- 依赖企业现有资质才能确认
